# Rental360

Rental360 is a full-stack Rental & Property Management System built using the MERN stack (MongoDB, Express.js, React, and Node.js).

This project is a web-based implementation of my previously developed **Salesforce Rental Management System**. The objective is to recreate the same business workflow using the MERN stack while improving the user experience, application architecture, and scalability.

---

## About the Project

Managing rental properties manually can be time-consuming and error-prone. Rental360 helps property owners manage rooms, tenants, rent payments, maintenance requests, and property details from a single dashboard.

This project focuses on building a real-world application with secure authentication, role-based access, REST APIs, and a responsive user interface.
